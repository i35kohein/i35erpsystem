# Scope 0 — App Shell & Shared Components (small-detail audit, desktop → mobile)

Audited by main agent. Files: `src/App.tsx` (shell/topbar/fab/toasts), `src/components/Navigation.tsx`, `src/index.css` (design system), `src/components/common/{RightFilterDrawer, CustomDropdownMenu, GlobalSearchModal, ConfirmDeleteModal, UserRoleSwitcher, HoverTooltip, DateFilterSelector}.tsx`, `src/components/ui/dialog.tsx`.

## Findings

| # | Location | Desktop detail | Mobile impact | Fix recommendation | Priority |

| S1 | CustomDropdownMenu.tsx (menu: `absolute z-50 w-56`) | In-place absolute popover anchored to button; `menuAlign` right/left/group-left, `-left-8` group offsets | No portal → menus clip inside any ancestor with `overflow:hidden` (workspace-panels, card containers); on phones, `right-0` menus near left edge extend past the left viewport edge (`max-w-[calc(100vw-2rem)]` only caps width, not position) → content off-screen, no scroll | Portal the menu to body; on `max-width:767px` position `fixed` with viewport clamping (left:8px/right:8px), or render as bottom-sheet-style action list; keep max-h + scroll | P1 |

## Good patterns to replicate (from shell)
- RightFilterDrawer: portal + backdrop + swipe-close + focus return + safe-area footer + 85vw cap.
- Topbar: hamburger/search at 44px (h-11 w-11) on mobile; title truncates instead of wrapping; action row never breaks layout.
- CSS seatbelts: `#main-content-scroll { overflow-x: clip }`, `scrollbar-gutter: stable` (no layout shift), safe-area env() everywhere, print styles resetting fixed positioning.
- Mobile touch floor in CSS (40px controls / 36px table icons) applied via `.basic-ui` — single source of truth.
- Landscape-phone accommodation and `workspace-panel` internal-scroll model keep tables usable.

## Top 5 worst offenders (shell)
1. S1 — dropdowns clip/escape viewport on mobile (no portal).
2. S2 — tooltip flash on touch taps.
3. S4 — topbar actions silently cut off on phones.
4. S3 — FAB/toast anchors assume a bottom nav that doesn't exist (inconsistent).
5. S12 — Radix dialog primitive is a mobile trap if ever adopted.
