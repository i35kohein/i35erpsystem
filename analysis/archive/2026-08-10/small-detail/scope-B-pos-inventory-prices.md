## Good patterns to replicate (found in scope)

1. **POS numpad** (PosL1110): `md:hidden` on-screen 3×4 keypad with `h-11` keys, `inputMode="numeric"`, ⌫ — ideal for cashiers on phones.
2. **POS sticky checkout bar** (PosL1215): full-width `z-40` bottom bar with `env(safe-area-inset-bottom)` padding, `max-w-[220px]` CTA, label swap (`hidden sm:inline`/`sm:hidden`), plus matching `pb-16 md:pb-0` on the scrolled parent.
3. **POS payment tiles** (PosL824): `min-h-[56px]`, icon + name + category, flex-wrap — good height/width balance (only the `min-w-[150px]!` needs a tweak for 320px).
4. **POS split-payment rows** (PosL947): `flex-col sm:flex-row` — stacks on mobile, inline on desktop, with Auto-Fill.
5. **Inventory cards-over-table enforcement** (InvL1486): `resize` listener forces card view <768px while keeping the desktop toggle.
6. **Inventory touch-size convention** (InvL1531): `h-10 w-10 lg:h-8 lg:w-8` — 40px on touch, 32px on desktop. Use everywhere.
7. **Inventory filter popup modal** (InvL3534): mobile pill → centered portal modal `z-[70]`, `px-3 py-2.5` rows, ESC + backdrop close — clean replacement for hover dropdowns.
8. **Inventory matrix sticky column** (InvL1995): `sticky left-0 z-30` model column + `min-w-max` + `overscroll-x-contain` — correct wide-table mobile UX (also applied in the print sheet).

1. **Inventory Profit view is a fixed table on phones** (InvL1910) — the one view that got no card fallback, so `whitespace-nowrap` MMK prices crush the part name to ~70px on a 360px screen.
